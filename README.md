## Sobre mí

Trabajo en la frontera entre el software y el hardware: me interesan los sistemas completos, desde el microcontrolador que lee un sensor hasta el modelo que interpreta esos datos en la nube.

- Desarrollando un **SaaS de mantenimiento industrial con IA**, combinando RAG sobre documentación técnica con datos de sensores en tiempo real.
- Especializándome en **agentes de IA, RAG y reinforcement learning**.
- Experiencia práctica con **Raspberry Pi, ESP32 y STM32** (HAL, I²C, firmware bare-metal).
- Aprendiendo arquitecturas cloud y despliegue de sistemas en producción.
